# 短信安全文本分类与模型评估

> 课程项目展示稿｜文本分析 · 分类评估 · 业务决策

## 项目概览

本项目以虚构的移动通信运营商为业务场景，探讨如何识别垃圾短信，同时减少正常短信被错误标记的风险。基于公开英文短信语料，使用 SAS Visual Text Analytics 设计和调整分类规则，并分析精确率、召回率及错误案例。

这是课程项目，不是企业上线项目。本文为整理后的展示草稿，公开前请确认课程规则与素材使用权限。

## 业务问题

垃圾短信规则过于宽松可能漏掉风险信息；过于严格则可能误伤正常的个人短信和服务通知。因此，本案例优先考虑减少正常信息的误判，并将命中规则的短信交由人工复核，而非直接自动拦截。

## 数据与方法

- 数据来源：[UCI SMS Spam Collection](https://archive.ics.uci.edu/dataset/228/sms+spam+collection)。
- 原始语料包含 5,574 条英文短信；去除完全重复的文本后，分析样本为 5,160 条。
- 检查重复、缺失及标签边界案例；识别联系渠道、奖品诱因、行动指令和紧迫表达等文本特征。
- 使用 SAS Visual Text Analytics 构建、调整垃圾短信分类规则；通过精确率、召回率和具体误判、漏判分析效果。

## 规则调整结果

| 指标 | 基准规则 | 调整后规则 |
| --- | ---: | ---: |
| 精确率（Precision） | 77.63% | 92.29% |
| 召回率（Recall） | 88.63% | 78.35% |
| 正常短信误判数量 | 164 | 42 |
| 垃圾短信漏判数量 | 73 | 139 |

在这批课程数据的内部比较中，调整后的规则减少了正常短信误判，但漏掉了更多垃圾短信。这个取舍符合模拟场景中优先减少误伤的目标，同时说明方案不能直接用于自动拦截。

## 错误分析

- 正常短信也可能包含电话号码，因此单独依赖号码可能造成误判。
- 一些垃圾短信使用短号码、分隔号码或收费描述，现有规则可能无法识别。
- “call now”等表达既可能出现在促销短信，也可能出现在个人对话中，需要结合上下文。

## 局限与下一步

- 上述规则是在同一批短信上设计和评估的，并非独立测试集结果，因此可能高估对新数据的效果。
- 数据是历史英文短信，不代表当前中国或东南亚市场，也不能直接推断线上表现。
- 下一步应在不参与规则调整的独立数据上重新测试，并检查号码格式、语言变化及误判成本。
